## Trust Boundaries

| Boundary | Descrição |
|----------|-----------|
| Repositório git local → origin remoto | Commits reescritos localmente não estão no remoto até o force-push |
| Repositório git → clones de colaboradores | Após force-push, clones antigos ficam divergentes e precisam ser atualizados |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | git history (commits 402bc32, 01e5d74) | mitigate | git filter-repo remove o blob de config.yaml de todos os commits; gc --prune=now remove blobs órfãos |
| T-05-02 | Information Disclosure | origin/main (remoto) | mitigate | git push --force-with-lease atualiza o remoto com o histórico reescrito |
| T-05-03 | Tampering | Reescrita acidental de commits não relacionados | mitigate | filter-repo com --path --invert-paths é cirúrgico — afeta apenas commits que tocaram config.yaml |
| T-05-04 | Information Disclosure | Clones existentes de colaboradores | accept | Clones antigos retêm o histórico; comunicação ao time é responsabilidade do operador — fora do escopo técnico deste plano |
</threat_model>
