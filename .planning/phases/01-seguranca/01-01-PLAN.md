    Passo 1 — Substituir senha em config.yaml:
    Leia erp-bridge-aws/config.yaml. Localize o campo que contém a senha (tipicamente `password:`, `db_password:`, ou `oracle_password:`). Substitua o valor da senha pelo placeholder literal: `SENHA_ROTACIONADA_CONFIGURE_VIA_ENV`. Mantenha todos os outros campos intactos (host, port, user, database, etc.).

    Passo 2 — Adicionar ao .gitignore:
    Adicione a seguinte linha ao `.gitignore` (se ainda não existir):
    ```
    erp-bridge-aws/config.yaml
    ```
    Verifique se já existe com `grep "erp-bridge-aws/config.yaml" .gitignore`. Se existir, não duplique.

    Passo 3 — Expurgar senha do histórico git:
    Execute via git filter-branch para remover a senha do histórico. Use o valor EXATO da senha lida em config.yaml no passo 1. Substitua `SENHA_EXATA_AQUI` pela senha real encontrada:

    ```bash
    git filter-branch --force --index-filter \
      "git rm --cached --ignore-unmatch erp-bridge-aws/config.yaml" \
      --prune-empty --tag-name-filter cat -- --all
    ```

    Após o filter-branch, force o garbage collection:
    ```bash
    git reflog expire --expire=now --all
    git gc --prune=now --aggressive
    ```

    Passo 4 — Fazer commit dos arquivos limpos:
    ```bash
    git add erp-bridge-aws/config.yaml .gitignore
    git commit -m "sec(SEC-01): remover credencial oracle do config.yaml e adicionar ao gitignore"
    ```

    IMPORTANTE: Após o commit, o arquivo config.yaml existe localmente com o placeholder mas não será rastreado pelo git em commits futuros. A senha real deve ser configurada via variável de ambiente `ORACLE_DB_PASSWORD` ou injetada no servidor AWS antes de reiniciar a bridge.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | erp-bridge-aws/config.yaml | mitigate | Remover senha do arquivo e expurgar histórico git com filter-branch; adicionar ao .gitignore |
| T-01-02 | Elevation of Privilege | Oracle ERP (credencial comprometida) | mitigate | Rotacionar senha imediatamente no sistema de origem antes de qualquer commit |
| T-01-03 | Information Disclosure | git history | mitigate | git filter-branch + gc --prune=now para remover blobs com a senha de todos os refs |
| T-01-04 | Information Disclosure | config.yaml em produção AWS | accept | Arquivo existe localmente no servidor; acesso ao servidor requer autenticação SSH — risco residual aceitável |
</threat_model>
