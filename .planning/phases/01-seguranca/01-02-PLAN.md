## Trust Boundaries

| Boundary | Descrição |
|----------|-----------|
| Internet → POST /api/auth/login | Requisições não autenticadas; qualquer IP pode tentar login |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Denial of Service | LoginRL (in-memory) | accept | Rate limiter in-memory é suficiente para instância única; não persiste entre restarts (comportamento aceitável para v1 — reiniciar servidor zera contadores) |
| T-02-02 | Spoofing (IP) | GetClientIP / X-Forwarded-For | mitigate | GetClientIP usa LAST entry de X-Forwarded-For (set pelo proxy confiável Traefik), não o primeiro — previne spoofing de header pelo cliente |
| T-02-03 | Elevation of Privilege | Brute-force de credenciais | mitigate | LoginRL.Allow(ip) bloqueia após 5 tentativas em 15 min → HTTP 429, consulta ao banco não é feita |
| T-02-04 | Information Disclosure | Resposta diferente para email inexistente vs senha errada | accept | LoginHandler já retorna mesma mensagem para ambos os casos ("E-mail não encontrado ou senha inválida") — timing side-channel é risco residual aceitável em v1 |
</threat_model>
