De backend/handlers/config.go:
```go
// sanitizeDBErr loga o erro interno do banco e retorna uma mensagem genérica ao cliente.
// Uso: sanitizeDBErr(w, http.StatusInternalServerError, "contexto", err, "[Prefix]")
func sanitizeDBErr(w http.ResponseWriter, status int, userMsg string, err error, prefix string) {
    log.Printf("%s %s: %v", prefix, userMsg, err)
    jsonErr(w, status, userMsg)
}
```

Padrões problemáticos que DEVEM ser substituídos:
```go
// Padrão 1 — substituir por sanitizeDBErr:
http.Error(w, err.Error(), http.StatusInternalServerError)
// → sanitizeDBErr(w, http.StatusInternalServerError, "mensagem genérica", err, "[Prefix]")

// Padrão 2 — substituir por sanitizeDBErr:
http.Error(w, "texto: "+err.Error(), http.StatusInternalServerError)
// → sanitizeDBErr(w, http.StatusInternalServerError, "texto", err, "[Prefix]")

// Padrão 3 — substituir por sanitizeDBErr (mesmo sendo 400):
jsonErr(w, http.StatusBadRequest, err.Error())
// → sanitizeDBErr(w, http.StatusBadRequest, "mensagem genérica", err, "[Prefix]")
```

Padrões que JÁ são seguros e NÃO devem ser alterados:
```go
http.Error(w, "Unauthorized", http.StatusUnauthorized)
http.Error(w, "Method not allowed", http.StatusMethodNotAllowed)
http.Error(w, "Invalid request body", http.StatusBadRequest)
jsonErr(w, http.StatusNotFound, "Registro não encontrado")
```
