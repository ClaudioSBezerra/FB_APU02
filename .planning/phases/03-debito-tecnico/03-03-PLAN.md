<objective>
Remover o serviço Redis do `docker-compose.prod.yml`. Redis está configurado mas não
é importado nem usado em nenhum arquivo `.go` do backend — é alocação pura de recursos
em produção (256 MB de memória reservada) sem retorno.

Itens a remover:
1. Variável de ambiente `REDIS_ADDR=redis:6379` no serviço `api`
2. Dependência `redis: condition: service_started` no serviço `api`
3. Bloco completo do serviço `redis:` (image, container_name, sysctls, volumes, networks, command, healthcheck, deploy)
4. Volume `redis_data:` na seção `volumes:`

Purpose: Eliminar 256 MB de alocação de memória e um container desnecessário em produção.
Output: docker-compose.prod.yml sem nenhuma referência a Redis.
</objective>

  <action>
Ler o arquivo completo e aplicar as seguintes remoções cirúrgicas:

1. No serviço `api`, remover a linha:
   ```yaml
         - REDIS_ADDR=redis:6379
   ```

2. No serviço `api`, remover o bloco `depends_on` para redis:
   ```yaml
         redis:
           condition: service_started
   ```
   (preservar as outras dependências como `db: condition: service_healthy`)

3. Remover o bloco completo do serviço `redis:` incluindo todos os seus sub-campos
   (image, container_name, restart, sysctls, volumes, networks, command, healthcheck, deploy).

4. Na seção `volumes:` no final do arquivo, remover:
   ```yaml
     redis_data:
       driver: local
   ```

Após as edições, verificar que o arquivo é YAML válido executando:

