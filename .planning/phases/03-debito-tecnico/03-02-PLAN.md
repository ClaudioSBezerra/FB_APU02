```go
// ANTES:
db.Exec(`UPDATE erp_bridge_config SET fbtax_email = $2 WHERE company_id = $1`, companyID, *req.FBTaxEmail)

// DEPOIS:
if _, err := db.Exec(`UPDATE erp_bridge_config SET fbtax_email = $2 WHERE company_id = $1`, companyID, *req.FBTaxEmail); err != nil {
    log.Printf("[ERPBridge] Erro ao atualizar fbtax_email: %v", err)

```

ATENÇÃO: Para as chamadas dentro de blocos que já têm fluxo de resposta HTTP ao redor
(por exemplo, dentro de um handler que já retornou ou já reportou erro), usar apenas
`log.Printf` sem `return` — a operação pode ser best-effort (log e continuar).

Para chamadas que são críticas (UPDATE que define estado de configuração), usar
`sanitizeDBErr` e retornar se o caller ainda não enviou resposta:
```go
if _, err := db.Exec(`...`); err != nil {
    sanitizeDBErr(w, http.StatusInternalServerError, "Erro ao atualizar configuração", err, "[ERPBridge]")
    return
}
```
